# XFreedom Android — открытая сборка 0.1.0

Это исходный рецепт нативного Android-приложения на официальных SFA + sing-box.
Обе версии фиксированы в `upstream.lock.json`. `prepare.py` извлекает точные
Git-объекты, меняет название, идентификатор приложения и ссылок, значок и тему,
отключает установку чужих обновлений и резервное копирование средствами Android.
Исходники проекта, лицензии и SHA-256 каждой подготовленной исходной записи доступны
в каталоге сборки. Существующий сайт не переносится и не заменяется.

## Сборка

Из корня репозитория:

```bash
python3 apps/android/prepare.py --output .android-build
bash apps/android/build.sh .android-build
```

Нужны Git, Python 3.12+, Go 1.26.7, JDK 17, Android SDK 37.1, Build Tools 37.0.0,
NDK 28.0.13004108, `make`; версии совпадают с закреплёнными исходниками upstream.
`ANDROID_HOME` указывает на SDK. Workflow `Android Open Edition` устанавливает
зависимости и выполняет те же команды. Создание каталога подготовки атомарно;
существующий каталог не перезаписывается. Для новой подготовки задайте новый путь.

Первый артефакт — **ARM64, Android 7+, debug APK**. Он использует временную тестовую
подпись CI. Стабильные обновления такой подписью не гарантируются. Это не Play-релиз.
Папка `apps/android/dist` появляется только после успешной сборки: APK, полный
подготовленный исходный код, рецепт, уведомления о лицензиях и контрольные суммы.
Наличие workflow или исходников не означает, что APK уже собран или испытан на телефоне.

## Подключение к имеющемуся single-VPS

Установщик `infra/solo/render.py` теперь создаёт приватный файл
`clients/xfreedom-android.json` рядом с другими клиентскими конфигурациями.
Он включает только **реально настроенные установщиком** Hysteria2 Salamander и
VLESS REALITY. Hysteria2 Native и TUIC не добавляются фиктивно.
Передайте файл на телефон приватным каналом и импортируйте через раздел профилей.
Затем выберите профиль и подключитесь, подтвердив системный запрос Android VPN.
Удалённые профили используют собственную схему `xfreedom://import-remote-profile`.
Встроенного публичного сервера, учётной записи или оплаченной подписки здесь нет.

Для отдельного каталога серверов:

```bash
python3 infra/solo/android_profile.py --catalog /private/catalog.json --output /private/xfreedom.json
sing-box check -c /private/xfreedom.json
```

Каталог имеет вид `{"schema":1,"endpoints":[...]}`. Типы: `hy2-native`, `tuic`,
`hy2-obfs`, `reality`. Поля и проверки находятся в `android_profile.py`.
Каждый endpoint содержит `id`, `kind`, `server_ip`, `port`, `server_name` и
клиентские credentials своего протокола. Адрес сервера — IP: так запуск туннеля
не зависит от незашифрованного bootstrap DNS. Обновление адресов требует нового профиля.
Один IP и UDP-порт не могут одновременно представлять разные слушатели.

## Поведение и границы

- Auto использует sing-box URLTest, интервал 1 минута, допуск 120 мс. Значения —
  начальные параметры, не измеренная оптимальность для России. Проверки простаивающей
  группы могут приостанавливаться. Это не 24/7 агент и не обучаемый Decision Engine.
- URLTest отправляет HTTPS-пробы к gstatic через кандидатов. URL можно сменить через
  `--probe-url`. Доступность этой страницы не подтверждает звонки, видео или все приложения.
- В профиле нет прямого fallback; DNS over HTTPS идёт через выбранный туннель.
  Захватываются IPv4 и IPv6. Фактическое отсутствие утечек проверяется на устройстве.
- При падении процесса до/после работы VPN блокировку обеспечивает системный
  Android «Блокировать соединения без VPN», который пользователь включает в настройках.
  `strict_route` сам по себе не даёт такой гарантии на Android.
- Переключение не переносит существующий TCP-сеанс между внешними IP. Возможен
  разрыв звонка или загрузки; обещания «без единого обрыва» нет.
- TLS проверяется, доверенный публичный сертификат встроен. REALITY private key,
  пароли БД и ключи Control Center/Qdrant не экспортируются. Клиентские credentials
  остаются секретными данными; скрытое поле UI не делает их неизвлекаемыми.

## Ещё не реализовано в интеграции XFreedom

SSH/HTTP payload мастер, совместимость с закрытыми `.ehi`/TLSVPN форматами,
Xray XHTTP, AmneziaWG, подписанные профили с отзывом устройства, полноценный
Decision Engine по операторам, проверка приоритетных приложений и магазинные релизы.
Наличие отдельных протоколов в upstream не означает их настройку на наших серверах.

Производственный допуск требует установки APK, прохождения трафика через свой VPS,
проверок DNS/IPv6/kill switch, Wi-Fi↔LTE, сна, неверного сертификата, отказа узла и
перезапуска. Нужен стабильный release signing key и утверждённая модель распространения.
Для закрытого клиента следует отдельно проектировать стек с подходящими лицензиями;
эта GPL-сборка не выдаётся за закрытую.
